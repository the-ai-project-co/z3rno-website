# Reporting Security Issues

The z3rno team takes security issues seriously. This repo is a static marketing/docs site with no backend, so the attack surface is limited, but we still want to hear about anything — dependency vulnerabilities, XSS in rendered content, secrets exposure, etc.

To report a security issue, email [security@z3rno.dev](mailto:security@z3rno.dev) and include the word "SECURITY" in the subject line.

Please do not open a public GitHub issue for security reports.
